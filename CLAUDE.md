# Notes for AI assistants

Read **[README.md](README.md)** first — it explains what this repository is for,
how to install/use the tool, and the license.

To install, start, health-check or drive the tool (especially the `grna` CLI), use the
**`diana` skill**: [.claude/skills/diana/SKILL.md](.claude/skills/diana/SKILL.md). Agents without
skill support can read that file directly; its `scripts/grna.sh` / `scripts/grna.ps1` run the CLI
from the Docker image with the current directory mounted.
